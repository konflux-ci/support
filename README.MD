# Konflux Community Support

Welcome to the **Konflux Community Support** repository! 👋

This repository is dedicated to providing support, answering questions, and resolving issues for users of the Konflux. Whether you are encountering a bug, have a configuration question, or need guidance on a specific component, the community and maintainers are here to help.

---

## 🆘 How to Get Help

We use GitHub Issues to track and manage support requests. This ensures that your questions are routed to the right people and that solutions are visible to the entire community.

### 1. Search First
Before opening a new ticket, please [search existing issues](../../issues) to see if your question has already been answered or if a similar problem is currently being investigated.

### 2. Open a Support Request
If you can't find a solution, please file a new request using our standard form.

👉 **[Click here to Open a Support Request](../../issues/new?template=support_request.yml)**

### 3. What to Include
When filling out the form, please be as detailed as possible to help us assist you better. You will be asked to provide:

* **Urgency:** (Low, Medium, High, Critical) - *Please reserve Critical for production-blocking issues.*
* **Topic:** The area this issue is relevant to.
* **Application & Component:** Which specific part of Konflux is affected.
* **Tenant ID:** (If applicable).
* **Question/Description:** A detailed explanation of the problem.
